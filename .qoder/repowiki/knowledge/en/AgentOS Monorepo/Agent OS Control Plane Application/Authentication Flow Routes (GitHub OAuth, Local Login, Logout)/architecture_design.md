Each route is a Next.js App Router handler (`route.ts`) under `app/auth/` with `dynamic = 'force-dynamic'`, delegating all cryptographic and session logic to the shared `src/auth/auth` module. The flow splits into three paths: GitHub OAuth starts at `/auth/github` which builds an authorization URL and sets an `OAUTH_COOKIE`; the callback at `/auth/github/callback` verifies the state/code exchange via `verifyCallback` + `exchangeGitHubCode`, then swaps the temp cookie for a long-lived `SESSION_COOKIE`. Local login at `/auth/local` issues a session directly when `isLocalhostBypassAllowed` permits it, supporting both GET and POST with form-based `returnTo`. Logout at `/auth/logout` enforces origin mutation via `enforceBrowserMutationOrigin` before clearing the session cookie. Dependency direction is strictly inward: routes depend only on `src/auth/*` helpers and never on domain services.
