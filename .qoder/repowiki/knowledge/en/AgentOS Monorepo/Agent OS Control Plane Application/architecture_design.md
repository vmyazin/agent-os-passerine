The module is a single Next.js App Router project where `app/api/**/route.ts` handlers delegate all business logic to layered services under `src/application` (projects, runs, configuration, inbox, workflow reconciliation, artifact cleanup, runtime), with `src/http` providing typed contracts, authenticated request wrappers, and route registration helpers. Cross-cutting concerns are split into sibling directories consumed uniformly: `src/auth` implements GitHub OAuth and local login session handling used by both API and UI routes; `src/persistence/repository-factory.ts` abstracts storage behind an in-memory or Neon-backed repository interface so every application service stays storage-agnostic; `src/ui` contains shared React components and view models reused across `app/*` page routes. Background work (artifact cleanup cron, local reconciliation loop, workflow reconciliation) is launched from the application layer rather than per-route, and startup wiring lives in `instrumentation.ts` alongside the route handlers.
