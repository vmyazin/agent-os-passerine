The module is a documentation-only leaf organized into three areas: `architecture/` holds cross-package architectural decisions (artifact storage, durable workflows, goal loop, Kimi runtime, threat model, trusted GitHub publisher) that reference the monorepo's package boundaries (`packages/core`, `packages/adapters`, `apps/control-plane`, `apps/cli`, `agentos`) defined in `architecture/README.md`; `superpowers/plans/` and `superpowers/specs/` pair dated implementation plans with their corresponding design specs (e.g. bounded-goal-loop, email-inbox, kimi-runtime, local-experiment-projects, frozen-acceptance-dod, multi-project); `progress.md` tracks completed foundation steps, verification boundaries, and remaining product stages. The directory structure enforces a separation between long-lived architecture decisions and time-stamped feature evolution artifacts.
