Single-file provider class `ManagedAgentsRuntimeProvider` in `provider.ts` implements the adapter's own `ManagedAgentsProvider` interface (extended from `@agentos/core`'s `RuntimeProvider`) and exposes a factory `createManagedAgentsRuntimeProvider` via `index.ts`. The module is layered into clear concerns: `sdk-contract.ts` defines a narrow structural facade over `@anthropic-ai/sdk` 0.117.1 so generated beta types never leak into public signatures; `normalization.ts` translates raw Managed Agents events into the canonical `RuntimeEvent` shape; `errors.ts` provides typed error subclasses (`ConfigurationError`, `ConflictError`, `LimitError`, `ProviderError`); `types.ts` declares the adapter-specific configuration, limits, environment, handle, and session-access contracts consumed by callers. Remote resource identity uses `agentos.local_id`/`agentos.config_digest` metadata keyed by project-scoped IDs, with an in-memory `Map` cache per agent/environment and single-flight deduplication via `#serializeSync`. Session ownership is enforced through a high-entropy HMAC-derived capability stored in session metadata and validated on every mutating call. Networking and built-in web egress are gated by policy flags, and all remote calls go through a shared `#wrap` helper that enforces byte/event/stream/reconnect limits defined in `DEFAULT_LIMITS`.
