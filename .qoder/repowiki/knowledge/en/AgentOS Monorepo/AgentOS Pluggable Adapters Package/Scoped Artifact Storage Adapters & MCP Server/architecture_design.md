The module exposes a uniform `ArtifactStore`/`ArtifactAdminStore` contract (re-exported from `@agentos/core`) behind two concrete adapters: an in-memory store (`in-memory.ts`) backed by a `Map` plus an in-memory manifest, and an R2 adapter (`r2.ts`) that wraps the AWS SDK v3 S3 client through a small `R2SdkClient` abstraction so it can be unit-tested without real R2. Both adapters share a manifest layer (`manifest.ts`) that persists logical artifact identity in Postgres via a `DomainRepository`, implementing a two-phase write lease (`beginWrite`/`finishWrite`) and a reservation-based deletion flow (`reserveDeletion`/`finalizeDeletion`) so R2 remains the immutable blob layer while Postgres is authoritative. Cursor pagination is implemented as signed, scope-bound tokens via `cursor.ts`. A separate HTTP handler (`mcp.ts`) implements the pinned MCP protocol `2025-06-18` JSON response subset, exposing only `artifact.get`, `artifact.put`, and `artifact.list` tools; every call is gated by a capability token verified against `ArtifactCapabilityVerifier` and charged through `quota.ts`'s HMAC-based quota store. The barrel `index.ts` re-exports all public constructors and types; tests live alongside sources and use a shared contract runner (`artifact-store-contract.ts`) plus per-backend fixtures (`test-support.ts`).
