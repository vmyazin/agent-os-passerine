The package is a flat adapter library with no shared runtime code; each subdirectory under `src/` implements one external dependency or concern (artifacts/R2/MCP, github, local-git, kimi, managed-agents, persistence/neon+in-memory, trigger) and exposes its own `index.ts`. The package root `src/index.ts` re-exports every adapter so consumers import from `@agentos/adapters` uniformly. Cross-child wiring happens at the consumer layer via `src/runtime/routing.ts`, which selects among runtime providers (Kimi vs Managed Agents) based on configuration, while `persistence` provides the shared `DomainRepository` contract that both `github` and `trigger` depend on for durable state. All adapters are pure SDK wrappers around third-party services (Cloudflare R2, Neon Postgres, GitHub API, Anthropic APIs, Trigger.dev) and communicate with each other only through these typed contracts rather than direct imports.
