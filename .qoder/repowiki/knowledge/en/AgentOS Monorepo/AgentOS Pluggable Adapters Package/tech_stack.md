TypeScript ESM package built with tsc; shared dependencies across adapters include `@agentos/core` (domain contracts), `drizzle-orm` + `@neondatabase/serverless` for Postgres-backed persistence, `@modelcontextprotocol/sdk` for artifact MCP tooling, `@anthropic-ai/sdk` for runtime providers, `@octokit/auth-app` for GitHub integration, and `@trigger.dev/sdk` for workflow orchestration.
