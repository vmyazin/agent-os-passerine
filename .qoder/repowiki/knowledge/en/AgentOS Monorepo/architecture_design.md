The workspace root wires five child modules through pnpm workspaces (`apps/*`, `packages/*`) and enforces a strict dependency order with Turborepo: `core_package` is the foundational layer consumed by `adapters_package`, which in turn is used by both `control_plane_app` (Next.js HTTP API) and `cli_app` (Node CLI), while `agentos_config` provides the declarative YAML workspace format consumed by both the CLI and the control plane. Cross-cutting concerns—database schema migrations (`drizzle.config.ts`), Trigger.dev workflow deployment (`trigger.config.ts`), end-to-end tests (`playwright.config.ts`), and unit tests (`vitest.config.ts`)—are rooted at the workspace level so all children run against the same toolchain. Shared TypeScript settings are centralized in `tsconfig.base.json` (strict mode, ES2022 target, Bundler module resolution) and inherited by every package, and `turbo.json` declares task caching and `^build`/`^lint`/`^typecheck` ordering so each child only declares its own targets without re-implementing orchestration.
