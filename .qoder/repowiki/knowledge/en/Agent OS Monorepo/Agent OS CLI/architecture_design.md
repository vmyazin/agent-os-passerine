The module is a thin Node.js binary (`apps/cli/src/index.ts`, declared as `bin.agentos` in `package.json`) that bootstraps I/O adapters (stdout/stderr/env/cwd/stdin) and delegates to `runCli(argv, io)` in `main.ts`. `main.ts` is the central orchestrator: it resolves configuration paths via `workspace.ts`, loads config files through `config-files.ts`, builds an `ApiClient` from `api-client.ts` using URL/token from flags or `AGENTOS_URL`/`AGENTOS_API_TOKEN` env vars, and dispatches parsed commands via a `switch` on `command.kind`. Local-only commands (`help`, `version`, `init`, `config.validate`, `config.plan`, `config.apply`) are handled inline; all other commands are forwarded to `executeRemoteCommand` in `commands.ts`, which maps each `RemoteCommand` kind to an `ApiRequest` `{method, path, body?, idempotencyKey?}`. Output formatting is centralized in `output.ts` with a single `renderResult` used for both success and error JSON/text. The only runtime dependency is `@agentos/core` (for `loadAgentOsConfig` and `planConfigChange`); everything else is built on Node's `node:util` `parseArgs` and `node:fs/promises`. Types in `types.ts` define a discriminated-union `Command` that flows from parsing through execution to remote dispatch.
