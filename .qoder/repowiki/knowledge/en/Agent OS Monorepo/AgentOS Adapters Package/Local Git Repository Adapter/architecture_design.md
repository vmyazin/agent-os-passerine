The module is organized around a strict security boundary: `git.ts` exposes only two entry points — `assertContainedRepository`, which realpath-resolves and confines paths under a `workspacesRoot`, and `runGit`, which spawns the `git` binary with a whitelist of safe plumbing subcommands (`rev-parse`, `ls-tree`, `cat-file`, `hash-object --stdin`, `mktree`, `commit-tree`, `update-ref`, `status`) plus per-subcommand flag allowlists and an env whitelist restricted to author/committer identity keys. All higher-level logic depends on this gate.

- `initialize.ts` creates brand-new repos via `execFile` (bypassing the plumbing allowlist by design) inside a freshly `mkdir`'d directory whose name is validated against a strict regex; it disables global/system git config so every repo starts from a deterministic clean slate and cleans up on failure.
- `source-snapshot.ts` implements a `TrustedSourceSnapshotIngestor` that reads a pinned commit tree via `ls-tree -r -z`, validates each path through a `safePath` guard, enforces file/total size limits, and materializes a canonical JSON bundle into an `ArtifactStore`.
- `publisher.ts` builds deterministic content-addressed commits by hashing blobs with `hash-object --stdin`, assembling trees bottom-up with `mktree`, and stamping commits with `commit-tree` using fixed author/committer dates derived from the authorization's `issuedAt`; it persists a phase checkpoint (`blobs_created` → `tree_created` → `commit_created` → `ref_created`) in a shared `PublicationStore`, treating `ref_created` as the durable terminal phase because Postgres constraints prevent local publications from reaching PR phases.
- `index.ts` re-exports the public surface; tests live alongside sources (`*.test.ts`, `publisher.postgres.test.ts`) and a shared `test-support.ts`.

Dependency direction is strictly inward: `initialize`, `source-snapshot`, and `publisher` all depend on `git.ts`; nothing in `git.ts` depends on them. The publisher also imports shared policy/manifest types from `@agentos/core` and reuses `PublicationPhase`/`PublicationStore` contracts from the sibling GitHub adapter.
