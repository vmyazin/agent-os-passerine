Built on Next.js App Router with a server-component-first layout: `layout.tsx` wraps every route in an `app-shell` containing a sidebar (`AppRailNav`, `AppRailSignOut`, `AppRailStatus`) and loads page-level session via `readPageSession()` plus rail counts via `fetchRailCounts()`. Each feature area has a matching folder under `app/` (projects, runs, inbox, configuration, setup) whose `page.tsx` is an async server component that calls `controlPlaneService()` from `src/application/runtime` to fetch data and renders shared UI primitives from `src/ui/*`. A parallel `app/api/` tree exposes REST-like handlers using the shared `handleApi(request, { authorize, output }, handler)` wrapper from `src/http/api`, which centralizes authentication (`requireApiAuthentication`), Zod-based response validation (`projectListProjectionSchema`, `runProjectionSchema`, etc.), and error handling. Auth flows live under `app/auth/` (GitHub OAuth redirect/callback, local login, logout) and use cookies (`OAUTH_COOKIE`, `secureCookie`). Route params are validated via `boundedPathId` before being passed into service methods. Global error/loading states are provided by `error.tsx` (client component) and `loading.tsx` at the app root.
