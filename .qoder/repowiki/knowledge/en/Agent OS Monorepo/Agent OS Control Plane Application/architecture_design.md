The module is organized as a Next.js App Router project where `app/api/*` route handlers delegate to `src/http` (route wrappers, contracts, authenticated helpers) which in turn call into `src/application` (domain services like projects, runs, configuration, inbox, workflow reconciliation, artifact cleanup, runtime). Cross-cutting concerns are split into sibling directories: `src/auth` provides GitHub OAuth and local login session handling consumed by both API and UI routes; `src/persistence/repository-factory.ts` abstracts storage behind an in-memory or Neon-backed repository interface used by all application services; `src/ui` contains shared React components and view models reused across `app/*` page routes. Startup wiring lives in `instrumentation.ts` and the route handlers themselves, with background work (artifact cleanup cron, local reconciliation loop, workflow reconciliation) launched from the application layer rather than per-route.
