The workspace root wires together four runtime packages via pnpm workspaces (`apps/*`, `packages/*`) and enforces a strict dependency order with Turborepo: `core_package` is the foundational layer consumed by `adapters_package`, which in turn is used by both `control_plane_app` (Next.js HTTP API) and `cli_app` (Node CLI). Shared TypeScript settings are centralized in `tsconfig.base.json` (strict mode, ES2022 target, Bundler module resolution), while per-package configs inherit from it. Cross-cutting concerns—database schema migrations (drizzle.config.ts), Trigger.dev workflow deployment (trigger.config.ts), end-to-end tests (playwright.config.ts), and unit tests (vitest.config.ts)—are rooted at the workspace level so all children run against the same toolchain. The `agentos_config` package provides the declarative YAML workspace format that both the CLI and the control plane consume to resolve agents, models, environments, and pipelines.
