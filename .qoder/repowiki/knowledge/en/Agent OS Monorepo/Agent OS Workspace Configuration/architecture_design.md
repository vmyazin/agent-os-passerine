This module is a configuration-only leaf containing the schema-driven manifests consumed by the `agentos` CLI. The default manifest `agent-os.yaml` defines a minimal starter (one model, one agent, one pipeline, permissive policies) used by `pnpm agentos init`. `example.yaml` extends it with a commented-out Moonshot/Kimi model profile and routing hints. `passerine.yaml` is the production e2e workspace defining a five-step feature pipeline (specifier → planner → implementer → reviewer → verifier), each step bound to a dedicated agent with its own tools, MCPs, environment, and inline prompt; environments are isolated cloud runtimes with limited networking, and a sealed environment is reserved for the trusted verifier. All three files share the same v1 schema: top-level keys `project`, `models`, `agents`, `environments`, `pipelines`, `policies`, `budgets`, `goals`, and `runtime`. Policies enforce protected paths, binary/symlink restrictions, file-size caps, and allow/deny lists for tools and MCPs. Budgets cap workflow and daily spend plus concurrency and admission reserve. The README documents CLI entry points (`init`, `config validate/plan/apply`) and security constraints around repository ownership, no-follow/exclusive file ops, and remote command auth via `AGENTOS_URL`/`AGENTOS_API_TOKEN`.
